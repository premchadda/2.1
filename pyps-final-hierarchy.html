1. Route & Navigation Hierarchy

L1
PYP Landing — All Exam Categories
/pyps
Shows exam-category grid (SSC, Banking, Railways, UPSC…) with PYP counts per category. Like Testbook's main PYP page.
↓
L2
Exam Category — All Exams with PYPs
/pyps/:examCategory   (e.g. /pyps/ssc)
Lists all exams in SSC that have PYPs (CGL, CHSL, MTS, CPO, GD, JE…). Each exam card shows total paper count + year range + latest paper badge.
↓
L3
Exam PYPs — Year-Grouped Paper List
/pyps/:examCategory/:examSlug   (e.g. /pyps/ssc/cgl)
The core page. Tier filter + year chips + year-grouped sections. Each card: date+shift, Q/marks/min, attempts, Attempt+PDF CTA. This is where 90% of competitor features live.
↓
L4
Paper Attempt — Test Interface
/pyp/:pypId/test   (already exists)
Full-screen test interface. Post-attempt: AI analysis, topic weightage, cut-off comparison, re-attempt mode.

6. Data Model Gaps to Fill

Critical (blocks hierarchy)
tests.exam_id — seed PYPs have exam_id: null. Must populate for exam-scoped PYP pages. Run a migration/script to link existing PYPs to their exam by parsing title or tag.
tests.exam_category_id — same gap. Populate from exam.categoryId lookup.
tests.pyq_year — column exists (migration 055) but ensure every PYP has it. Parse from sub_category or title if missing.
Important (enables features)
tests.shift — NEW column (VARCHAR or INT). Currently shift is only in the title string. Add column for clean filtering/display.
tests.attempt_count — column exists but must be kept updated (increment on each attempt).
tests.pdf_asset_id — NEW or reuse banner_asset_id. For "Download PDF" CTA.
exam_yearly_data.cutoff — may need a dedicated JSONB field for cut-off trend table.
