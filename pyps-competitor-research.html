PYP Page UI — Competitor Research

How Testbook & Oliveboard design their Previous Year Papers pages, and what to adopt for /pyps

🔵
Testbook
testbook.com/ssc-cgl-exam/previous-year-papers
  • • Year-grouped sections ("2025 — 98 Tests")
  • • Per-paper cards: date+shift, user count, Q/marks/mins
  • • Stage/Tier selector + Year chip filter (2016–2026)
  • • "Load More" per year + "Load More Years"
  • • PDF download + Online attempt (dual CTA)
  • • Social proof: "11,356k Students Improved"
  • • Topic weightage table + Cut-off trend table
  • • Pass upsell banner ("Unlock 44,000+ PYPs")
🟢
Oliveboard
oliveboard.in/ssc-cgl-previous-year-papers
  • • "Why to attempt" 3-feature card row
  • • Horizontal PYP carousel (date+shift cards)
  • • Each card: marks / questions / duration / lock icon
  • • Feature bullet list (86 Tier-1, 7 Tier-2, 132 GK...)
  • • Topper showcase: "Rank #1" photos with exam
  • • Email/phone lead-capture form
  • • Exam-category landing page (icon grid)
🎯
Your Page (/pyps)
TagPage.jsx + AnimatedHero.jsx
  • • Blue→indigo→cyan hero, floating dots
  • • Flat test list (no year grouping)
  • • Search + Series + Type dropdowns
  • • Single "N Tests Available" badge
  • ✗ No year grouping / date+shift
  • ✗ No attempt counts / social proof
  • ✗ No tier/shift filter
  • ✗ Configured decoratives missing

Recommended Implementation Priority

P0 — High Impact
  • 1. Group tests by year (extract from title/date field)
  • 2. Show date + shift in each card title
  • 3. Add attempt count per paper (backend field)
  • 4. Add year-chip quick filter row
  • 5. Add social proof badge ("X attempts this month")
P1 — Medium
  • 6. Fix broken decoratives (file-icon-glow, history-orbit, float-up)
  • 7. Dual CTA on card: Attempt + Download PDF
  • 8. "Load More" per year section (progressive disclosure)
  • 9. Year-range chip in hero (e.g. 2018–2024)
P2 — Later
  • 10. Tier/Stage selector (if exams support tiers)
  • 11. "Why attempt PYPs" 3-card feature row
  • 12. Topic-wise weightage trend table
  • 13. Cut-off trend analysis chart
