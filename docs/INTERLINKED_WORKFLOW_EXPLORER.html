Active Milestone
1. User Interaction (Frontend)

Student enters phone OTP or Google OAuth credentials in Login.jsx. Upon successful verification, student selects target exam (SSC CGL 2026 Tier-1) in OnboardingWizard.jsx.

2. System Engine & Security

Backend hashes passwords via bcrypt, generates httpOnly JWT cookies with CSRF tokens. Redis session manager revokes any existing active token on a second device to enforce single-device integrity.

Admin activity logger records user registration/login IP. Admin Users Manager (UsersManager.jsx) updates active user counts and enrollment rosters in real-time.
