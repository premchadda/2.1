3. Backend (apps/backend)

Express 4 API server — port 5001. 82 route files in api/routes + 32 module route files. JWT auth + optional TOTP 2FA, PostgreSQL, Redis, Socket.IO, Sentry.

Entry Point — src/app-port5001.js (939 lines)
Port 5001, binds 0.0.0.0. Startup sequence: dotenv → validate env (DATABASE_URL, JWT_SECRET, JWT_REFRESH_SECRET, FRONTEND_URL) → JWT strength check (≥32 chars, mixed case + digits + symbol) → blocked known-compromised secret SHA-256 blocklist (leaked-in-git-history guard) → optional Sentry init → compression + strong ETag + trust-proxy 1 → helmet (full CSP in prod) → json/urlencoded 1MB limit → cookies → morgan → monitoring → publicIdResponse → trace → CORS allowlist → validateOrigin → generalLimiter → requestDedup → responseCache → cacheControl → route mounts (73 app.use lines) → /api/sessions router → mountExtractedRoutes(app) → Swagger → Sentry error handler → notFoundHandler → errorHandler → testConnection(5 retries) → runMigrations → warmPools (read/write split) → initRedis → initQueues → messageBroker.init + registerUserEventSubscribers → createServer + initWebSocket → server timeout 30s / headersTimeout 31s → listen → BullMQ repeatable reminder job (every 6h) → startScheduler + startOutboxPoller + startAttemptCleaner → subscription expiry process on startup + hourly. Graceful shutdown closes scheduler/outbox/cleaner, drains email queue, closes queues/Redis/DB. Uncaught exceptions route through fatalShutdown.
Required Env Vars
DATABASE_URL, JWT_SECRET (strength enforced + compromised-hash blocklist), JWT_REFRESH_SECRET, FRONTEND_URL.
Optional: DATABASE_READ_URL (read pool), REDIS_URL, STORAGE_PROVIDER (local|s3|supabase), EMAIL_PROVIDER (none|sendgrid|aws|smtp), SMS_PROVIDER (none|twilio|aws), FORTSPY_URL, GOOGLE_CLIENT_ID, ADMIN_PANEL_URL, ADMIN_API_KEY, RAZORPAY_KEY_ID/SECRET, SENTRY_DSN, AI_FREE_HOURLY_LIMIT (50), AI_PRO_HOURLY_LIMIT (500), QUEUE_* tuning, WORKER_*_CONCURRENCY, INSTANCE_ID, ENFORCE_HTTPS
Middleware Order
compression → helmet (CSP) → express.json/urlencoded → cookieParser → morgan → monitoring → publicIdResponse → trace → CORS (allowlist) → validateOrigin → generalLimiter → requestDedup → responseCache → cacheControl → static mounts (/uploads, /assets/avatar, /storage with auth guards + imageOptimization) → adminIpAllowlist → route mounts → Swagger → Sentry → notFoundHandler → errorHandler
Swagger / API Docs
setupSwagger(app) from src/api/docs — serves openapi.json + swagger UI of all mounted routes. API_ENDPOINTS.md documents admin endpoints.

Soft-delete: is_deleted/deleted_by/deleted_at + is_active; recycle-bin aware
RLS: Event trigger auto-enables on new CREATE TABLE; user-scoped policies via current_user_id() (099/100 consolidated)
Runtime DDL: initTables() idempotent DDL + reconcileRelationships() FK backfill each boot
Dual pools: write DATABASE_URL + read DATABASE_READ_URL with warmPools()
Audit: audit_logs + restrictAdminOrigin + per-admin RBAC permissions
Encryption: PII-at-rest pgcrypto with key-resilience guard (m104)
