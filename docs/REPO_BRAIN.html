3. Backend (apps/backend)

Express 4 API server — port 5001, PostgreSQL, Redis, Socket.IO

Entry Point
src/app-port5001.js — port 5001, binds 0.0.0.0
Startup: dotenv → validate env (DATABASE_URL, JWT_SECRET ≥32 chars, FRONTEND_URL) → test DB connection (5 retries) → createServer + initWebSocket → listen → background: initTables(), initRedis(), initQueues(), scheduled reminders
Required Env Vars
DATABASE_URL, JWT_SECRET, JWT_REFRESH_SECRET, FRONTEND_URL, REDIS_URL, STORAGE_PROVIDER (local|s3|supabase), EMAIL_PROVIDER (none|sendgrid|aws|smtp), SMS_PROVIDER (none|twilio|aws), FORTSPY_URL, GOOGLE_CLIENT_ID, ADMIN_PANEL_URL, ADMIN_API_KEY, RAZORPAY_KEY_ID/SECRET
Middleware Order
helmet (CSP) → express.json → cookieParser → morgan → monitoring → publicIdResponse → trace → CORS (allowlist) → rateLimiters → cacheControl → route mounts → notFoundHandler → errorHandler

Key Design Patterns
Dual-ID: SERIAL id (internal) + public_id_uuid UUID + generated public_id (API-exposed, prefixed: usr_, tst_, qst_, etc.)
Soft-delete: is_deleted / deleted_by / deleted_at trio + is_active flag
RLS: Enabled on user-scoped tables via current_user_id(). Event trigger auto-enables on new tables.
Runtime DDL: postgres-helpers.js initTables() creates/alters ~25 tables on every boot (idempotent)
FK Reconciliation: reconcileRelationships() auto-adds 40+ missing FKs + indexes on every boot
JSONB auto-stringify: ~25 tables have JSONB columns auto-stringified on insert
