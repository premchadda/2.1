Modular Architecture

Trstprep uses a modular structure with feature-based organization. The backend has migrated to a modules-based architecture with dedicated routes, services, and helpers per feature. Models are organized by domain (user, exam, test, question, etc.).

🗄️ Database Schema

ℹ️
Dual Database Architecture

The application uses a dual approach: MongoDB with Mongoose for complex documents and PostgreSQL via Supabase with a helper layer providing MongoDB-like API. All tables support soft delete via is_active flag and have created_at/updated_at timestamps.
