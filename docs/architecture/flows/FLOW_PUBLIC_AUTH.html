Public Funnels & Authentication Boundary Flow

A comprehensive deep dive detailing the unauthenticated marketing endpoints (Home/About/Contact), the global useAuth context engine binding frontend states to the backend JWT validator, and robust fallback/Interception mechanisms catching expired credentials seamlessly.

🚦 1. Public App Navigation Tree

These routes are strictly unauthenticated. They represent the "top of the funnel" meant to draw public traffic towards the login screens or free test offerings. They mount outside of ProtectedRoute.jsx.

⚛️ 2. Comprehensive JWT State Handshake

The entire React UI transforms instantly based on the presence of a valid `trstprep_token` string stored in localStorage. The `AuthContext` runs a verify request the instant the DOM mounts.

The Context Execution Sequence

1. App Initialization (`AuthContext.Provider`)
`useEffect` executes on `mount`. Reads `localStorage.getItem('trstprep_token')`.
2. Token Verification Strategy
Axios implicitly attaches the JWT. Hits GET `/api/auth/me`. Express validates signature utilizing `jsonwebtoken` package vs ENV secret.
3. Identity Hydration (`setUser(data)`)
Upon 200 OK, the generic context exposes `{ user: { name: 'Admin', role: 'admin' }, logout() }` globally to any `useAuth()` hook.
4. Automatic Interception (`axios_config.js`)
If token is expired, Server returns 401. Axios Interceptor catches error, calls `logout()` forcing a redirect to `/login` seamlessly.

// The global wrapper shielding deep APIs
const protectRoute = async (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  
  if (!token) return res.status(401).json({ message: 'No token' });
  
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded; // Attach for controllers
    next();
  } catch (err) {
    res.status(401).json({ message: 'Invalid/Expired token' });
  }
};
