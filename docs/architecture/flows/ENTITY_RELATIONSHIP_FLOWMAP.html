🔗 Entity Relationships

📚→📋
Exam → Test Series
Relationship: One-to-Many (1:N)
  • One Exam can have multiple Test Series Bundles
  • Bundles define hierarchy via sections JSONB (e.g. Tier I, PYP)
  • Foreign Key: test_series.exam_id → exams.id
Example: SSC CGL Exam → "SSC CGL Mock Test Series 2026 (Tier I & Tier II)"
📋→📝
Test Series → Tests
Relationship: One-to-Many (1:N)
  • One Test Series contains multiple Tests
  • Each Test belongs to one Test Series
  • Foreign Key: tests.test_series_id → test_series.id
Example: "SSC CGL Tier 1 Series" → Test 1, Test 2, Test 3...
📚→🎯
Exam → Quizzes
Relationship: One-to-Many (1:N)
  • One Exam can have multiple Quizzes
  • Quizzes can also be topic-based (independent)
  • Foreign Key: quizzes.exam_id → exams.id (nullable)
Example: SSC CGL → "Daily GK Quiz", "Reasoning Mini Quiz"
📚→📖
Exam → Study Materials
Relationship: One-to-Many (1:N)
  • One Exam has multiple Study Materials
  • Materials can be: Notes, PDFs, Videos, Syllabus
  • Foreign Key: study_materials.exam_id → exams.id
Example: SSC CGL → "Quant Notes", "English PDF", "Syllabus"
🎯→❓
Quiz → Questions
Relationship: One-to-Many (1:N)
  • One Quiz contains multiple Questions
  • Questions have options and correct answer
  • Foreign Key: questions.quiz_id → quizzes.id
Example: "GK Quiz" → Q1, Q2, Q3... (10-20 questions)
📝→❓
Test → Questions
Relationship: One-to-Many (1:N)
  • One Test contains multiple Questions
  • Questions are mapped to test via junction table
  • Foreign Key: test_questions.test_id → tests.id
Example: "SSC CGL Mock 1" → 100 Questions

Entity Relationship Summary 
// Entity Relationship Overview (Topic-Centric)

EXAMS (Central Hub)
  ├── 1:N → TEST_SERIES (Bundles)
  │     ├── Organizes into Stages/Tiers
  │     └── 1:N → TESTS (Mocks, PYQs, Sectional)
  │           └── M:N → QUESTIONS (via test_questions)
  │
  ├── 1:N → SUBJECTS
  │     └── 1:N → CHAPTERS
  │           └── 1:N → TOPICS
  │                 ├── 1:N → QUIZZES
  │                 ├── 1:N → QUESTIONS
  │                 └── 1:N → STUDY_MATERIALS

// Key Relationships:
// - Exam is the parent entity, but learning is Topic-Centric
// - Test Series groups Tests via dynamic JSONB sections
// - Topics are the lowest common denominator linking content
// - Every Question is tagged with [Subject, Chapter, Topic]

⚡ Quick Reference

🌐
Frontend Routes
  • /exams/:slug → Exam Details
  • /exams/:slug/test-series → Test Series for Exam
  • /test-series/:id → Test Series Details
  • /tests/:id → Take Test
  • /quizzes/:id → Take Quiz
  • /study-materials/:id → View Material
📡
Key API Endpoints
  • GET /api/exams → List all exams
  • GET /api/exams/:slug/test-series → Get test series
  • GET /api/test-series/:id/tests → Get tests in series
  • GET /api/exams/:slug/quizzes → Get quizzes
  • GET /api/exams/:slug/materials → Get study materials
