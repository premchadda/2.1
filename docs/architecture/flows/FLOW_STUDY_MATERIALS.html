1
Subject Landing
User sees all study materials with dynamic counts (topics, videos, PDF, tests) calculated from related tables
2
Subject Detail View
Shows chapters list with content counts per chapter. Videos, PDFs, and tests are fetched for each chapter.
⚡ Count Calculation
Counts are calculated dynamically from subjectVideos, subjectPdfs, and topicTests tables for accurate real-time data.
3
Chapter Content
Each chapter contains:
  • Videos - Video lessons with duration, thumbnail
  • PDFs - Study notes with file size, pages
  • Topic Tests - Practice tests linked to chapter
4
PRO Content Access
Videos/PDFs with isPro=true are locked for free users. PRO users get full access.

Known Issues & Technical Debt
Issues identified in study materials flow
⚠️ Hardcoded Subject Icons
Subject icons and colors are defined in frontend code rather than database. This limits dynamic configuration.

Recommendation: Move icon/color definitions to study_materials table or create a separate theme configuration.
📝 Progress Tracking Not Implemented
The study_progress table exists but progress tracking UI is not fully implemented. Users cannot see their learning progress across subjects.

Dynamic Count Calculation
Real-time aggregation from related tables
study.js - Count Calculation Helper 
// Helper: Calculate study material counts
async function calculateStudyMaterialCounts(dbHelpers, materialId) {
  // Count chapters
  const chapters = await dbHelpers.find('chapters', { 
    studyMaterialId: materialId, 
    isActive: true 
  });
  
  // Count videos
  const videos = await dbHelpers.find('subjectVideos', { 
    studyMaterialId: materialId, 
    isActive: true 
  });
  
  // Count PDFs
  const pdfs = await dbHelpers.find('subjectPdfs', { 
    studyMaterialId: materialId, 
    isActive: true 
  });
  
  // Count tests (topic_tests + direct tests)
  const topicTests = await dbHelpers.find('topicTests', { 
    studyMaterialId: materialId, 
    isActive: true 
  });
  const directTests = await dbHelpers.pool.query(
    'SELECT COUNT(*) FROM tests WHERE subject_id = $1 AND is_active = true',
    [materialId]
  );
  
  return {
    topics: chapters.length,
    videos: videos.length,
    pdf: pdfs.length,
    tests: topicTests.length + parseInt(directTests.rows[0]?.count || 0)
  };
}
