🔌 API Endpoints

GET/api/studyGet all study materials
GET/api/study/:slugGet study material by slug
GET/api/study/:slug/chaptersGet chapters for a subject
GET/api/admin/study-materialsAdmin: Get all materials
POST/api/admin/study-materialsAdmin: Create material
PUT/api/admin/study-materials/:idAdmin: Update material
DEL/api/admin/study-materials/:idAdmin: Delete material
GET/api/admin/chaptersAdmin: Get chapters
POST/api/admin/chaptersAdmin: Create chapter
