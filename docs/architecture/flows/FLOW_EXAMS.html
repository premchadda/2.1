Known Issues & Technical Debt
Issues identified in exam flow
⚠️ Hardcoded Exam Data
StaticContent.jsx contains hardcoded fallback content for SSC CGL exam details. This should be migrated to database-driven content.

Location: apps/frontend/src/components/exams/StaticContent.jsx
Issue: Lines 25-180 contain static SSC CGL content

See Hardcoded Data Migration Plan for details.
📝 Default Values in API
The /api/exams/:slug/year endpoint returns default fallback values when data is missing:
  • notification: "June {year-1}"
  • applicationStart: "{year-1}-07-01"
  • eligibility: "Bachelor's degree in any discipline"
  • ageLimit: "18-32 years"
These should be stored in database instead of hardcoded.

⚡ 8. Fallback Mechanisms

1

Database First

All API routes try to fetch from PostgreSQL database first using global.dbHelpers

2

JSON Fallback

If database returns empty or errors, routes fallback to JSON files in /data/collections/

3

Sample Data

ExamDetails.jsx has hardcoded SAMPLE_YEARLY_DATA as ultimate fallback

4

Coming Soon Page

If exam has minimal content, shows ComingSoon.jsx

// Backend fallback pattern
let categories = await global.dbHelpers.find('examCategories', { isActive: true });

// Fallback to JSON if database is empty
if (!categories || categories.length === 0) {
    categories = loadJsonData('examCategories');
}
