🔗 Entity Relationships

📚→📋
Exam → Test Series
Relationship: One-to-Many (1:N)
  • One Exam can have multiple Test Series Bundles
  • Bundles define hierarchy via sections JSONB (e.g. Tier I, PYP)
  • Foreign Key: test_series.exam_id → exams.id
Example: SSC CGL Exam → "SSC CGL Mock Test Series 2026 (Tier I & Tier II)"
📋→📝
Test Series → Tests
Relationship: One-to-Many (1:N)
  • One Test Series contains multiple Tests
  • Each Test belongs to one Test Series
  • Foreign Key: tests.test_series_id → test_series.id
Example: "SSC CGL Tier 1 Series" → Test 1, Test 2, Test 3...
📚→🎯
Exam → Quizzes
Relationship: One-to-Many (1:N)
  • One Exam can have multiple Quizzes
  • Quizzes can also be topic-based (independent)
  • Foreign Key: quizzes.exam_id → exams.id (nullable)
Example: SSC CGL → "Daily GK Quiz", "Reasoning Mini Quiz"
📚→📖
Exam → Study Materials
Relationship: One-to-Many (1:N)
  • One Exam has multiple Study Materials
  • Materials can be: Notes, PDFs, Videos, Syllabus
  • Foreign Key: study_materials.exam_id → exams.id
Example: SSC CGL → "Quant Notes", "English PDF", "Syllabus"
🎯→❓
Quiz → Questions
Relationship: One-to-Many (1:N)
  • One Quiz contains multiple Questions
  • Questions have options and correct answer
  • Foreign Key: questions.quiz_id → quizzes.id
Example: "GK Quiz" → Q1, Q2, Q3... (10-20 questions)
📝→❓
Test → Questions
Relationship: One-to-Many (1:N)
  • One Test contains multiple Questions
  • Questions are mapped to test via junction table
  • Foreign Key: test_questions.test_id → tests.id
Example: "SSC CGL Mock 1" → 100 Questions

 │ ├── 1:N → QUIZZES
 │ ├── 1:N → QUESTIONS
 │ └── 1:N → STUDY_MATERIALS

auth.js - Register Handler
// POST /api/auth/register
router.post('/register', async (req, res) => {
 const { name, email, password } = req.body

 // Check if user exists
 const existingUser = await dbHelpers.findOne('users', { email })
 if (existingUser) {
 return res.status(400).json({ 
 success: false, 
 message: 'User already exists' 
 })
 }

 // Hash password & create user
 const hashedPassword = await bcrypt.hash(password, 10)
 const user = await dbHelpers.insertOne('users', {
 name, email, 
 password: hashedPassword,
 role: 'user',
 isEmailVerified: false
 })

 // Send verification email
 await sendVerificationEmail(user)
 
 res.status(201).json({ success: true, data: user })
})

Login Flow
JWT token generation
auth.js - Login Handler
// POST /api/auth/login
router.post('/login', async (req, res) => {
 const { email, password } = req.body

 // Find user
 const user = await dbHelpers.findOne('users', { email })
 if (!user) {
 return res.status(401).json({ 
 success: false, 
 message: 'Invalid credentials' 
 })
 }

 // Verify password
 const isMatch = await bcrypt.compare(password, user.password)
 if (!isMatch) {
 return res.status(401).json({ 
 success: false, 
 message: 'Invalid credentials' 
 })
 }

 // Generate JWT token
 const token = jwt.sign(
 { id: user.id, role: user.role },
 process.env.JWT_SECRET,
 { expiresIn: '7d' }
 )

 res.json({ 
 success: true, 
 token,
 user: { id: user.id, name: user.name, email: user.email }
 })
})

// Helper: Calculate study material counts
async function calculateStudyMaterialCounts(dbHelpers, materialId) {
 // Count chapters
 const chapters = await dbHelpers.find('chapters', { 
 studyMaterialId: materialId, 
 isActive: true 
 });
 
 // Count videos
 const videos = await dbHelpers.find('subjectVideos', { 
 studyMaterialId: materialId, 
 isActive: true 
 });
 
 // Count PDFs
 const pdfs = await dbHelpers.find('subjectPdfs', { 
 studyMaterialId: materialId, 
 isActive: true 
 });
 
 // Count tests (topic_tests + direct tests)
 const topicTests = await dbHelpers.find('topicTests', { 
 studyMaterialId: materialId, 
 isActive: true 
 });
 const directTests = await dbHelpers.pool.query(
 'SELECT COUNT(*) FROM tests WHERE subject_id = $1 AND is_active = true',
 [materialId]
 );
 
 return {
 topics: chapters.length,
 videos: videos.length,
 pdf: pdfs.length,
 tests: topicTests.length + parseInt(directTests.rows[0]?.count || 0)
 };
}

// Score Calculation Algorithm
const totalQuestions = test.questions ?? questions.length;
const totalMarks = test.marks ?? (totalQuestions * 2);
const marksPerQuestion = totalQuestions > 0 ? totalMarks / totalQuestions : 0;
const negativeMarks = test.negativeMarking ?? 0;

questions.forEach((question) => {
 const selectedOption = answer?.selectedOption;
 const correctOption = question.correctAnswer;
 
 if (selectedOption === null) {
 unattempted++;
 } else if (selectedOption === correctOption) {
 correct++;
 } else {
 wrong++;
 }
});

// Final Score = (Correct × Marks) - (Wrong × Negative)
const score = (correct * marksPerQuestion) - (wrong * negativeMarks);
const accuracy = correct + wrong > 0 
 ? (correct / (correct + wrong)) * 100 
 : 0;

// Response Payload
{
 attemptId, testId, seriesId, testTitle,
 score: Math.max(0, score),
 totalMarks, totalQuestions,
 correct, wrong, unattempted,
 accuracy, timeSpent,
 rank, percentile, totalParticipants
}

🔒 Security Architecture

🔐

JWT Authentication

Tokens signed with JWT_SECRET, stored in httpOnly cookies. Token includes user ID for database lookup. 7-day expiry with refresh capability.

🛡️

Route Protection Middleware

• protect - Requires valid JWT token
• optionalAuth - Attaches user if token present
• admin - Requires admin role
• proPass - Requires active Pro subscription

✅

Input Validation

All user inputs validated with express-validator. SQL injection prevented through parameterized queries. XSS prevented through output encoding.

🔑

Password Security

Bcrypt hashing with salt rounds of 10. Passwords never returned in API responses. Reset tokens expire after 1 hour.

// Auth Middleware (auth/index.js)
export const protect = async (req, res, next) => {
 let token;
 
 // Check Authorization header
 if (req.headers.authorization?.startsWith('Bearer')) {
 token = req.headers.authorization.split(' ')[1];
 }
 
 // Also check httpOnly cookie
 if (!token && req.cookies?.token) {
 token = req.cookies.token;
 }
 
 if (!token) {
 return res.status(401).json({ message: 'Not authorized' });
 }
 
 const decoded = jwt.verify(token, process.env.JWT_SECRET);
 const user = await dbHelpers.findById('users', decoded.id);
 
 if (!user || user.isActive === false) {
 return res.status(401).json({ message: 'User not found or inactive' });
 }
 
 req.user = user;
 next();
};
